# Desktop Server

GPU-accelerated streaming apps using WebRTC or non-accelerated using VNC

With WebRTC, the video codec can be chosen: H.264 works in all browsers, H.265 only in browsers
that can decode it (e.g. Safari, Chrome with hardware decoding), and with AV1 the desktop is
started only on a node with an NVIDIA RTX PRO 6000 Blackwell or L4 GPU.
